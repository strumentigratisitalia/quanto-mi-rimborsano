# Quanto mi rimborsano

Calcolo della compensazione per voli in ritardo, cancellati o con imbarco negato (Reg. CE 261/2004 e UK261) e dell'indennizzo per treni in ritardo (Trenitalia, Italo, Reg. UE 2021/782), con il reclamo già scritto da copiare. Gratis, senza registrazione.

Sito: https://strumentigratisitalia.github.io/quanto-mi-rimborsano/

## Come funziona

Le distanze sono calcolate in linea d'aria (haversine) sui dati aeroporti di OpenFlights. Le regole sono verificate sui testi ufficiali a ottobre 2026, inclusa la riforma Reg. (UE) 2026/2202 in vigore dal 23 ottobre 2027. Nessun dato lascia il browser.

HTML, CSS e JavaScript puri, nessun build. Dati degli aeroporti: [OpenFlights](https://openflights.org/data) (ODbL). Il calcolo è indicativo e non sostituisce un parere legale. Segnalazioni e correzioni sono benvenute nelle issue.
